# Avaliação 01 – Programação Web Front-End

Este repositório contém os códigos desenvolvidos por Gabriel para a Avaliação 01 da disciplina de Programação para Web Front-End.

## Questões

1. **IMC** – Calcula o Índice de Massa Corporal e exibe uma mensagem.
2. **Votação** – Simula uma votação entre candidatos.
3. **Conversor de Temperatura** – Converte entre Celsius e Fahrenheit.
4. **Controle de Gastos** – Soma os gastos e alerta se ultrapassar o limite.
5. **Jogo de Adivinhação** – O usuário tenta adivinhar um número entre 1 e 10.
